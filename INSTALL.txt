dadada 安装说明（Chrome / Edge）
================================

1. 先解压 dadada.zip。
   Windows：右键压缩包，选择“全部解压”。
   macOS：双击压缩包。

2. 把解压后含有 manifest.json 的 dadada 文件夹放在固定位置。
   如果解压工具额外套了一层文件夹，就继续打开，找到直接含有 manifest.json 的这一层。

3. Chrome 地址栏输入 chrome://extensions 并按回车。
   Edge 地址栏输入 edge://extensions 并按回车。

4. 开启“开发者模式”。

5. 点击“加载已解压的扩展程序”（Edge 显示“加载解压缩的扩展”），
   选择第 2 步的文件夹。
   不要选择 ZIP 文件，也不要选择 icons 或 test 子文件夹。

6. 出现 dadada 扩展卡片即表示加载成功；把它固定到工具栏，刷新要使用的网页。

安装后请保留扩展文件夹，浏览器会继续从这里读取文件。
无需 Git、Node.js 或编译。未设置 AI 接口时，也可以使用本地摘要等功能。
AI 功能需要在扩展“设置”中填写你自己的接口地址、模型和 API Key。

如提示找不到清单文件：请确认已解压，并选择直接含 manifest.json 的文件夹。
如安装后看不到悬浮球：刷新普通网页；浏览器内部页面和扩展商店不能注入。
