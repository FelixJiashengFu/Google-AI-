悬浮在网页上的讲解助手：总结本页、划词解释、追问对话

AI 接口

填写任意 OpenAI 兼容接口后，才能使用逐段讲解、划词解释和追问。不填写也能使用本地摘要和页面结构。

填到 /v1 即可，扩展会自动补 /chat/completions。也可以直接填完整的 chat/completions 地址。

只保存在这台电脑的 Chrome 扩展本地存储里，发送时直接用于你填写的接口。

按服务商文档填写。本地模型示例：Ollama 地址 http://127.0.0.1:11434/v1，Key 随意填 ollama。

使用偏好

控制悬浮助手的行为，修改后记得保存。

打开面板时自动讲解本页
已连接 AI 时，每次打开面板会读取本页并生成一次讲解。
选中文字后显示「讲解」按钮
在页面上划选 4 个字以上，就在选区旁边浮出按钮。
双击空格开始截图
连续按两下空格，拖动选择区域；截图会自动复制并尝试粘到 ChatGPT。Alt+Shift+S 随时可用。

怎么用

  1. 点网页右下角的悬浮球，或按 ⌥⇧E / Alt+Shift+E 打开面板。
  2. 「本页」标签看概览；在网页上选中文字后点「讲解」，切到「划词」。
  3. 「问答」标签可围绕当前页连续追问；打开菜单里的「讲解这个页面」也能直接唤起。
  4. 在页面空白处连按两下空格（或 ⌥⇧S），拖动框选，截图会自动复制并尝试粘贴到 ChatGPT。

隐私与权限

页面正文只在你点击讲解、划词或提问时，发送到你填写的 AI 接口；不会经过其他服务器。 API Key 保存在 chrome.storage.local，不参与同步。 触发截图时，当前可见页面会被捕获并复制到剪贴板，随后粘贴到你打开的 ChatGPT；不会上传到其他服务器。 扩展需要读取所有网站的权限，是因为悬浮球要出现在任意页面；它不会在后台自动上传页面内容。
